# Ícones locais do aplicativo

Este diretório está reservado para arquivos efetivamente usados na interface. Phosphor foi escolhida pelo usuário; ainda não há novos ícones incorporados nem pacote/variante definidos. Se forem necessários arquivos locais, usar `assets/icons/phosphor/`; se a integração for por pacote, não duplicá-los aqui.

Registre biblioteca, link oficial, versão, licença e aprovação em [docs/design/ICONES.md](../../docs/design/ICONES.md). Depois, coloque arquivos locais em uma subpasta com o nome da família e inclua os avisos de licença correspondentes. Bibliotecas importadas por pacote não precisam de cópia aqui.

Referências do Mobbin permanecem em `docs/design/mobbin/`; não são assets distribuídos pelo app. Ícones de instalação/splash existentes permanecem nos caminhos atuais.
